## Why data, why now

Most ML projects don't fail because the model is wrong. They fail at the boring parts: unreliable pipelines, no monitoring, no reproducibility, no path to production. Those boring parts are what I've done for a decade. I'm now bringing that production discipline to pipelines and models, backed by a solid statistical foundation.
